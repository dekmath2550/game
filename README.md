# RETRO STAR 🚀

เกมยิงยานอวกาศสไตล์เรโทร เล่นผ่านเว็บบนคอมพิวเตอร์และมือถือ สร้างด้วย HTML, CSS และ JavaScript โดยไม่ต้องติดตั้ง dependencies

## วิธีเล่น

- กด Enter หรือปุ่มเริ่มภารกิจ
- WASD / ปุ่มลูกศร: เคลื่อนที่
- Space: กดค้างเพื่อยิง
- P / Esc: หยุดเกมชั่วคราว
- มือถือ: ใช้ปุ่มบนหน้าจอ หรือลากยานเพื่อเคลื่อนที่พร้อมยิง
- เก็บพลังสีเขียวเพื่อยิงสามทิศทางเป็นเวลา 8 วินาที
- บอสปรากฏทุก 3 ด่าน คะแนนสูงสุดบันทึกไว้ในเบราว์เซอร์

## เล่นบนเครื่อง

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้ทันที

## GitHub Pages

หลังอัปโหลดไฟล์ไปยัง repository ให้เปิด Settings → Pages เลือก Deploy from a branch แล้วเลือกสาขาที่เก็บไฟล์เกมและโฟลเดอร์ `/ (root)` จากนั้นกด Save

## ไฟล์

- `index.html`: หน้าเกม
- `style.css`: รูปลักษณ์และการแสดงผลบนมือถือ
- `game.js`: ระบบเกมและเสียงเอฟเฟกต์
